STIMULUS SPACE

Move the means. Keep the sample.

Sliders translate the same sample; changing spread or correlation reshapes it. Resample creates a new seeded sample. Means, SDs and correlation are population parameters: finite samples vary. Clouds are untruncated Gaussians; out-of-domain points are retained and reported. Manual clouds have no acceptance constraints. Use automatic search below for constrained sets.

Stimulus-space limits

These limits define the automatic generator's allowed space and set the graph and mean-slider ranges. Existing points are retained. Search rejects whole sets with any point outside the space; it never clips or moves individual points. The Gabor preset requires frequency > 0 and ≤ 35, and angle ≥ 0 and < 180°. This sets coordinate limits; it does not render Gabor images.

Axis limits and grid spacing

Grid lines and labels occur at multiples of each interval (for example, 0, 5, 10). Limits change the view without changing stimulus coordinates. Up to 200 grid lines per axis are supported.

Axes and slider ranges

Frequency is cycles per stimulus; angle is degrees. Canvas axes have different units; apparent slopes and distances depend on axis ranges. Physical view restores the configured stimulus-space limits.

Geometry search ranges

Templates propose category means and Gaussian shapes. They are candidate structures, not proof of a participant strategy. Simple and II templates use two clouds with shared population covariance. Conjunction templates use one corner cloud for A and three corner clouds for B, with equal total points in A and B.

Ready. Set stimulus-space limits above, then choose your constraints.

Automatic search supports up to 1,000,000 points per category, 10,000 requested sets, and 10,000,000 attempts; browser resources will usually limit practical sizes first. All requirements are checked together without relaxing them. The search stops when enough sets are found, at the attempt limit, or when cancelled. Failure to find sets does not prove they are impossible. Best linear accuracy is optimal only over the selected angle grid; vertical, horizontal, and AND accuracies are empirical optima in their rule families. Searching and accepting finite sets changes their sampling properties. Exported audits record settings, seeds, rule coefficients, and achieved accuracies.

LINES & CLASSIFICATION

Decision boundaries

Click two positions on the plot, or drag between them. The line extends across the graph. Escape cancels.

Find a separator between category groups

Assign each cloud to Category A, Category B, or Ignore. Multiple clouds can belong to either category. Rules classify two category groups; they do not create three or more separate classes.

Maximizes balanced accuracy: (A correct % + B correct %) / 2, using every selected point, including hidden clouds. Both label directions and all distinct thresholds are tested for each searched orientation, in units standardized by pooled within-cloud SDs. Straight-line search is best on this angle grid. Conjunction search tests all distinct pairs of sample cutoffs, all four AND directions, and both category mappings; it is exact for this empirical rule family. Neither predicts human accuracy. Conjunction search can be slow for very large samples; Cancel search stops it.

Rules stay fixed when clouds move. Accuracy updates using current points; click Refit to fit again. Conjunctions appear as L-shaped boundaries with the AND region lightly shaded. Trend lines describe variation within a cloud and do not by themselves classify categories. Save project includes lines and settings.
